# 像素太空 · Pixel Space

Three.js + Vite + TypeScript 技术原型 v0.3：第三人称 6DOF 太空飞行战斗 + 程序化星球降落 + 地表探索的垂直切片。不含外部美术/音频资源，全部程序化生成（噪声、Canvas 贴图、WebAudio）。

## 玩法闭环

1. **太空**：6DOF 飞行 + 波次战斗（小行星/无人机）
2. **降落**：飞近星球（<175 单位）→ 按 **F** → 黑屏转场
3. **地表**：下船以第三人称角色探索（收集 12 颗水晶）
4. **返回**：靠近停靠的飞船按 **F** → 起飞回太空，继续战斗

## 运行

```bash
npm install
npm run dev      # 打开 http://localhost:5173
```

生产构建：

```bash
npm run build    # tsc 类型检查 + vite 打包
npm run preview  # 预览产物
```

## 操作

| 按键 | 太空 | 地表 |
|---|---|---|
| 鼠标 | 战机转向（第三人称跟随） | 角色视角 |
| W / S | 前进 / 后退 | 前进 / 后退 |
| A / D | 左 / 右平移 | 左 / 右 |
| Q / E | 翻滚 | — |
| Space / C | 上升 / 下降 | 跳跃 / — |
| Shift | 加速 | — |
| 左键 | 射击 | — |
| F | 靠近星球降落 | 收集 / 返回飞船 |
| 1/2/3/4 | 切换像素风格 | 同 |
| Esc / R | 暂停 / 重生 | 暂停 |

## 四种像素风格（按 1/2/3/4）

1. **经典像素** — 低分辨率 + 最近邻放大
2. **体素** — 更低分辨率 + 8 级调色板量化
3. **精灵纸片** — 模型切换为面向相机的 2D 像素精灵（仅太空场景生效）
4. **CRT 复古** — 扫描线 + 暗角 + 降饱和

## 结构

```
src/
  main.ts       入口
  game.ts       双场景状态机（menu/space/landing/surface/over）+ 战斗 + 降落流程
  flight.ts     6DOF 飞行控制器 + 第三人称跟随相机
  character.ts  地表角色控制器（重力/地形碰撞/跳跃/动画/跟随相机）
  planet.ts     程序化星球（3D 噪声地表纹理 + 云层 + 大气辉光）
  terrain.ts    噪声地形（高度图 + 顶点着色 + 水面）
  noise.ts      确定性值噪声 + fBm（地形与星球共用）
  entities.ts   战机/敌人/子弹池/爆炸碎片/像素贴图
  fx.ts         星空 + 像素化后处理管线
  controls.ts   指针锁定与键盘输入
  sfx.ts        WebAudio 程序化音效
```
